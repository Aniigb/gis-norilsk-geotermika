Загрузка данных геотехнического мониторинга

Структура ведомости замеров — по ГОСТ 25358-2020 (прил. В, Д); оформление журнала мерзлотного надзора — по СП 25.13330.2020 и ВСН 01-89.
Шаблон ведомости (одна строка = одна точка замера):
Адрес объекта · Район · Скважина (литера) · Дата замера (ДД.ММ.ГГГГ) · Глубина скважины, м · Глубина точки, м · Температура, °C · Источник (журнал, файл)
Температура — со знаком «минус» для отрицательных значений; разделитель десятичных — точка или запятая. Адрес должен совпадать с адресом в базе (допустимы варианты написания). Новые адреса будут отклонены — сначала создайте карточку объекта.
⬇ Шаблон XLSX
Объектная ведомость геотермики — шаблон ООО «НПО «Фундамент» (файл вида «Геотермика <адрес>.xlsx»: лист «Замеры», глубины по столбцам, строка = скважина × дата). Раскладка распознаётся автоматически и запоминается для каждой организации; недостающая t наружного воздуха догружается из метеоархива на дату замера, t воздуха подполья — по корреляции с наружной
Адрес берётся из имени файла. Расшифровка извлечения показывается полностью (скважины, даты, точки, дубли).
📄 Отчёты обследований (Word .docx / PDF) — интеллектуальное распознавание: адрес, фундаменты, сваи/ростверк/оголовки, дефекты, подполье, продухи, условия эксплуатации, ремонты → предпросмотр → перенос в разделы карточки
📐 Ведомости геодезии (Excel / CSV / PDF) — распознавание строк «дата · марка · отметка/осадка», автоперенос во вкладку «Геодезия» карточки
🧠 Ведомость геотермики нестандартного шаблона (xlsx) — универсальный распознаватель структуры + запоминание шаблона за организацией
📥 Приёмка в центральную базу — каждая загрузка автоматически уходит в центральную БД (Supabase) со статусом «ожидает приёмки»; принятые вливаются в основную базу еженедельной задачей
Загруженные замеры сохраняются в браузере (localStorage) и сразу участвуют в графиках и статусах. Для включения в центральную базу передайте файл в АНО «АНИИГБ» им. М.В. Кима.
